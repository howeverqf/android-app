# FILM / CCD — Android APK через GitHub Actions

Это Android-проект с локальным интерфейсом камеры, плёночными и CCD-эффектами. Готовый APK собирается в GitHub Actions, компьютер не нужен.

## Собрать APK прямо с Android

1. В браузере телефона открой github.com и войди в аккаунт.
2. Создай **новый пустой репозиторий** (например `film-ccd-android`).
3. Загрузи **содержимое папки** `FILM_CCD_Android_Project` в корень репозитория, включая скрытую папку `.github/workflows`. Важно: `settings.gradle` должен находиться в корне репозитория, не внутри вложенной папки.
   - На телефоне GitHub иногда неудобно загружать папки. Можно включить «Версия для ПК» в Chrome или воспользоваться мобильным Git-клиентом, который поддерживает загрузку дерева файлов.
4. Открой **Actions → Build FILM CCD APK → Run workflow** (если кнопки нет, проверь, что файл `.github/workflows/build-apk.yml` загружен и Actions разрешены).
5. Дождись успешного завершения сборки. В разделе **Artifacts** скачай `FILM-CCD-Android-debug-APK`.
6. Распакуй скачанный ZIP, открой `app-debug.apk` и разреши установку из этого источника, если Android попросит.

APK отладочный, подписывается автоматически тестовым ключом GitHub runner. Для личной установки подходит; для публикации и безопасных обновлений нужна собственная постоянная подпись.

## Локальная сборка

JDK 17, Android SDK 35, Gradle 8.9: `gradle :app:assembleDebug`.

## Ограничения

APK не собран и не протестирован здесь на устройстве. Для камеры требуется разрешение Android. RAW RW2 не декодируется; JPEG/PNG и камера поддерживаются. Снимки сохраняются в `Pictures/FILM_CCD`. Пресеты — программные стилизации.
